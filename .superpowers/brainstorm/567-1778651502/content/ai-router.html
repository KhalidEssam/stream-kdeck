Multi-Provider AI Router Architecture

Desktop agent routes AI requests across providers to minimize cost · BYOK support for power users

System flow
📱 Mobile App
User presses AI button.
Sends action payload:
{ task: "summarize", context: "clipboard", prompt: "..." }

Mobile never touches API keys.
Never calls AI directly.
→ WS / LAN
🧠 AI Router
Lives inside the Desktop Agent
1. Classify task type (simple / medium / code / complex)
2. Check provider health + quota remaining
3. Select cheapest available provider
4. Fallback chain if provider fails
5. Rate-limit per user per month
6. Return response to mobile
Keys stored here only.
Encrypted in OS keychain.
Never leave the desktop agent.
Never sent to mobile or cloud.
→ HTTPS

Bring Your Own Key (BYOK)
For developers and power users
User enters their own Anthropic / Google / OpenAI API key in the desktop agent settings tray.
Their key takes full priority — bypasses all platform quotas and routing.
Cost is 100% theirs. Platform pays $0 for their AI usage.
Why this is a feature, not a workaround
Developers want full control of which model they use.
Claude Code users already have Anthropic API keys.
BYOK users get unlimited AI with zero quota warnings.
Perfect upsell: "bring your own key or use our pool at $8/mo."
