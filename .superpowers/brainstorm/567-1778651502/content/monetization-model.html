Key Risks & Mitigations
⚠️ App Store "non-functional app" rejection
If App Store listing says "Free" but app does nothing, it gets rejected or removed.

Fix: App Store listing clearly states "Requires Desktop License." First screen is a rich product preview + purchase CTA. App is functional as a purchase funnel — not broken.
⚠️ AI API cost overrun
1,000 active Pro users × heavy AI use = potential $3k–8k/month Claude API bills.

Fix: Monthly action quota per Pro user (e.g., 500 AI calls/month). Bring-your-own-key option for power users. Hard cap with graceful degradation.
✅ Investor MRR narrative
The $8/month Pro subscription is your recurring revenue story. One-time license sales are the funnel metric. Investors see: license holders → attach rate → MRR → growth rate. Clean SaaS signal despite the hybrid model.
✅ No 30% platform tax on core revenue
Desktop license sold on your own website = 100% margin. AI subscription via web billing = 100% margin. App Store / Play Store only distribute the free app. Zero platform cut on real revenue.
