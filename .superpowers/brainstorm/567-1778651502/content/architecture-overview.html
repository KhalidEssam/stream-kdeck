Recommended System Architecture

AI-Native Control Surface · Mobile App + Lightweight Desktop Agent · Hybrid LAN / Cloud

Client Layer
📱 Mobile App
  • React Native (Expo)
  • iOS + Android
  • iPad support
  • Configures layouts
  • Touch / gesture input
  • Stores profiles locally
  • Syncs to cloud
PRIMARY PATH
Local LAN · WebSocket
Phone and agent on same Wi-Fi network. 1–5ms latency No server costs Works offline
→ mDNS auto-discovery (Zeroconf / Bonjour)
→ QR code pairing on first connect
→ Encrypted WebSocket (WSS + local token)
FALLBACK PATH
Cloud Relay · Supabase Realtime
Used when not on same network (office, travel, remote use). 50–150ms latency Cross-network Server cost applies
→ Agent maintains persistent Supabase channel
→ Mobile routes via cloud when LAN unreachable
→ Graceful auto-switch between paths
Execution Layer
🖥️ Desktop Agent
  • Node.js + pkg (tray icon)
  • Windows / macOS / Linux
  • WebSocket server
  • mDNS broadcaster
  • Active app detection
  • App icon extraction
  • Command execution engine
  • Global hotkey listener
  • Clipboard bridge
  • OBS WebSocket client
  • Local AI runner (optional)
External Service Integrations (Agent ↔ Services)
🤖 Claude API
AI macro execution, prompt pipelines, clipboard processing, code actions
🎬 OBS WebSocket
Scene switching, stream start/stop, source control, live detection
☁️ Supabase
Cloud sync, auth, profile storage, marketplace templates, Realtime relay
🔗 Webhooks
Zapier, Make, n8n, custom HTTP — triggered from agent or mobile directly
🎵 Media APIs
Spotify, system audio, media keys — agent reads system state
Local LAN path (primary, ~1–5ms)
Cloud relay fallback (~50–150ms)
Agent executes all system commands locally
Mobile app is configuration + control surface only
Supabase handles auth, sync, and cloud relay (one dependency)
