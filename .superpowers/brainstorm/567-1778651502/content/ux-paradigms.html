What makes it feel premium
📳
Haptic feedback
Precise haptics on every press. Feels like a physical button. iOS UIImpactFeedbackGenerator with "rigid" style.
🌊
Spring animations
Buttons physically depress on press, spring back on release. Physics-based, not linear tweens.
🌑
Dark mode first
Primary aesthetic. Looks stunning in a dark streaming room. Accent color system for personalization.
✅
Success animations
Green flash on successful action. Red pulse on failure. AI loading shimmer while processing.
📡
Live status
Real-time: connection state, active app, AI processing indicator, stream timer if OBS is live.
🎨
Icon quality
SF Symbols on iOS, Material Symbols on Android. Custom SVG support. Emoji supported natively.
Biggest UX mistakes competitors make — what to actively avoid
Touch Portal
First screen is a form asking for IP address and port. Feels like configuring a router. 30% of users never complete setup.
Macro Deck
Buttons designed for mouse interaction — too small for touch, no breathing room, grid feels like a spreadsheet.
Deckboard
Generic Material Design that feels like any productivity app. Zero personality. Nothing that makes you proud to show it on stream.
All of them
Drop users into an empty grid with zero guidance. No template suggestions, no onboarding path, no "here's what to do first."
All of them
Empty states are literal empty grids. Should be a beautiful state that actively guides users toward their first button.
