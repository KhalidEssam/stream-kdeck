Local LLM support — the differentiator no competitor has
🖥️ Ollama / LM Studio integration
The desktop agent can connect to a local Ollama instance running on localhost:11434. Users running local models (Llama 3, Mistral, Gemma, CodeLlama) can use them as a button action with zero API costs and zero data leaving their machine.

No competitor supports this. It's a 2-day integration that unlocks an entire community of privacy-conscious developers and AI enthusiasts.
Who cares about this?
  • Developers running Ollama already (large community)
  • Privacy-conscious users who won't use cloud AI
  • Air-gapped / corporate environments
  • Power users who want CodeLlama for code tasks
  • Anyone tired of API quotas and billing surprises
How AI becomes a moat, not a gimmick
Compounding personal workflow library
Every AI workflow a user builds is stored in their account. Over time: 20, 50, 100 custom prompt workflows, each tuned to how they work. This is the same switching cost as a Raycast extension library or an Alfred workflow collection — hours of investment that can't be exported to a competitor.
Deepest moat
System context no cloud-only competitor can access
Active app, window title, file name, clipboard state, OBS scene, process list — the agent knows the full system context at button-press time. An AI button that knows you're debugging a Node.js app in VS Code is fundamentally more useful than one that doesn't. Cloud-only competitors physically cannot replicate this.
Technical moat
Community workflow marketplace
When users can publish and share their AI workflows as installable templates, network effects kick in: more workflows → more users → more workflows. The marketplace becomes a content platform. "My full VS Code + Claude Haiku developer setup" as a one-click install is a growth engine competitors don't have.
Network moat
Workflow chaining depth
Multi-step pipelines (AI → system action → AI → webhook → AI) create workflows that are genuinely complex to replicate manually. A single button that summarizes an error, explains it, pastes the fix into the editor, and tweets a learning from it is 5 manual steps replaced. Users who build these chains don't go back.
UX moat
